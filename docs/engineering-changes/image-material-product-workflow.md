# Image-derived material and product workflow publication

## Change and scope

Publish ten personal image-material skills, portable bundle 0.15.0, and a new
product-image-to-turntable coordinator, version 0.1.0. Connect the existing
LuaCAD/product set through focused routes in digital-twin-iteration and
material-reference-lookdev. Keep existing geometry, normal/UV, consumer asset and
native-render gates. A shared handoff connects CAD units, thickness, material
regions, map scale, interface normals and actual saved/native bindings.

The material skills retain source identity, explicit optical alternatives,
layered graphs/values, generated appearance studies/contact sheets, registered
physical fields, native diagnostics and source/generated/native critique.
Conditional branches cover fine structure, coherent morphology, coat/substrate
ownership, triplanar/hex behavior and temporal mapping checks. Complexity follows
visible evidence rather than the number of shader sockets or texture files.

## Use and recovery

Install selected skill directories side by side. The combined route uses the
[personal index](../personal-image-material-skills.md) and current 16-product-skill
set. Discover the active project's maintained tooling before execution. The generic
skills do not install renderer binaries, a Blender service, a LuaCAD exporter,
product preparation adapters or a studio asset. Verify installed API/version
behavior instead of applying historical syntax or glass-shadow approximations
unconditionally.

Use one live renderer owner. A maintained direct native-USD route is distinct from
and cannot bypass a saved-Blender-asset receipt. Resume only matching input
revisions. Keep geometry fidelity, material identity, native support and movie
completion separate in the result.

This update publishes source and documentation to the personal fork and synchronizes
reviewed skills to the requesting workspace. Local installed copies are backed up
before updates. Roll back the publication using a normal revert; do not rewrite
inherited catalog history or force-push. Local rollback restores the preserved
per-directory snapshots rather than guessing which user-specific files changed.
