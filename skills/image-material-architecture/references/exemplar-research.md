# Learn mechanisms from an inspectable exemplar

Use when the user requests material research, when a reference suggests interacting responses the current architecture cannot express, or when a reconstruction remains generic after its maps are verified. Keep the result in the case record; do not add a skill for each material name.

## Select for explanatory value

Prefer an accessible authored graph with its dependencies, license, version and a representative image. Rank by distinct active mechanisms, independent spatial controls and consequential interactions. Total node count, a long preset interface, texture count and a marketing name do not establish optical complexity. A compact pearl can teach more about interference and scattering than a large inactive template.

Trace backward from the bound surface through inherited defaults, actual connections, channel extraction and numeric transforms. Record:

- Reachable scattering components and which are vertically layered versus spatially mixed. A node named `layer` can still be a mix; a name containing `transmission` can be a zero-weight helper.
- Each component's color/coefficient, roughness domain, normal/tangent frame, mask, scale and combination rule. Follow shared fields to all destinations, including those that suppress another feature.
- Every file's actual dimensions/encoding and atlas or repeating layout. Packed RGB channels are independent data until their wiring says otherwise. A white dust color connected as a mask is not automatically albedo.
- View-dependent nodes, geometric dependencies, simplifications and unreachable branches. An authored optical approximation is evidence of a construction choice, not proof of physical chemistry.

Resolve numeric semantics from the installed definition. Primitive BSDF roughness, perceptual roughness and glossiness are not interchangeable. Thin-film units also differ between shader interfaces. Compare the full conversion chain, including squaring, coat roughening and unit transforms; do not repair a mismatch with an unexplained gamma or color multiplier.

## Preserve what makes the construction complex

A narrow highlight core plus broad shoulder can require two scattering populations at the same point. Averaging two roughness values generally does not preserve their mixed angular response. Compare a single-width rival under controlled illumination before escalating to supported closure composition. Spatially alternating two finishes is a different hypothesis from simultaneous populations.

A coating can have its own surface normal while buried structure retains a different normal. Surface deposits may add both broad diffuse response and grazing sheen, with related but unequal masks. A single dirt mask wired identically into every property can erase those relationships. Carry source relationships as hypotheses to test on the new image, not universal laws.

A single OpenPBR surface has a fixed architecture. It may approximate a more general MaterialX stack, but do not silently collapse multiple independently controlled BSDFs into one roughness field. State what is lost; use supported composition or separate geometry when the defining response warrants it. Test native support before committing to elaborate map generation.

## Build a diagnostic atlas

Preserve the established shader ball, UVs, camera and balanced lighting. If the source maps are object-specific UDIMs, retaining them on the source object is the identity control; mapping a selected tile onto the ball is a separately labeled response-transfer experiment. It cannot establish source layout fidelity or seamlessness. Keep source repairs, adaptations and ablations distinct.

Capture verified native event selections and focused component interventions. Use [transport semantics](../../image-material-lobe-prompts/references/transport-semantics.md) for each image contract. A reflection event set can contain metal, coat and sheen together. Do not relabel it as one physical layer without a verified label mechanism. A black volume selection is not proof that subsurface scattering is absent: renderer event accounting and the selected expression must be established.

Verify the intervention in the effective bound graph before interpreting its image. A stronger constant value need not remove an inherited input connection. In composed USD, explicitly disconnect the input or bind an independently named control material with an explicit reference list; preserve the original geometry and UVs. Record the changed connection/value and material binding. Supersede an invalid control instead of using its small delta as evidence that the map has no influence. Check composition, adaptation and event classification before attributing unexpected behavior to the renderer.

For disputed interactions, render the combined candidate, each component disabled separately, and both disabled when needed. Layer-removal differences include changes to underlying throughput and can be signed; they are not additive positive lobes. If computing an interaction residual, define it explicitly, use raw linear data and common settings, and check sampling noise with a repeated or higher-sample control before interpreting a small signal. Keep exposure fixed in comparisons; label any separate visibility boost.

Inspect actual texture channels and final remaps beside the native response. Record whether a feature is visible at delivery size, not just in its map. Preserve failures: valid XML is not proof of native compilation, and a successful material render is not proof of every connected control's influence. For unfamiliar closure composition, check a known limiting case before using its outputs as behavioral references: a neutral, non-absorbing, zero-presence top component should reproduce the bypassed substrate under the model's declared semantics. Test the exact mixture/layer topology. If the identity fails, retain the source graph as construction evidence but quarantine native optical conclusions until the compatibility issue is resolved; a plausible black render can fail without a compiler error.

## Judge map-to-response quality on fixed mapped geometry

For this research mode, object-specific atlas seams, sculpted motifs and unfamiliar placement on a benchmark are expected. Keep UVs and geometry fixed across controls and evaluate occupied chart interiors. Do not spend the study repairing atlas transfer or reject a useful causal relation because the ball does not resemble the source object. A source-object beauty is useful when identity is being evaluated; it is not a prerequisite for a focused map/input influence test.

For each disputed field, retain the source channel, its actual transform/range, destination component, matched native event image and a field-disabled or declared-constant control. If UV correspondence is known, compare matching patches; otherwise mark patch correspondence unresolved instead of claiming raw texture/render pixels align. An evaluated-field debug view on the geometry can reveal which chart regions and values are actually sampled.

| Field / setting | Look for in the relevant response | Do not mistake for success |
| --- | --- | --- |
| Normal strength, direction and frequency | Highlight bending, split shapes and feature-scale relief; base and outer interfaces may differ | A purple file or changed beauty color without verified reflection-shape change |
| Roughness after its full remap | Changed reflection spread and breakup at fixed normals, illumination and material coverage | A nominal wide input range that collapses after remapping, or a reflection that changes only because the light changed |
| Reflection weight or component mask | Changed response amount or replacement at intended boundaries; underlying responses may also change | Treating a mask as roughness, or demanding that all other event sets stay identical when material replacement changes them |
| Conductor reflectivity versus diffuse pigment | Color in the appropriate event set and declared component | Forcing metal color into diffuse or accepting baked highlights in an intrinsic color field |
| Packed channels and sparse masks | Correct channel, numeric depth, polarity and influence in occupied/nonzero regions | Judging empty atlas area as material coverage, clipping a 16-bit mask, or assuming a filename describes its live use |

A large image delta establishes influence, not quality. Judge whether the intended feature profile, density, scale, boundaries and angular behavior survive, and whether quiet regions remain quiet. Record the expected response signature and failure signature so a new-image agent can compare generated fields with their own native lobe outputs. Keep causal map tests distinct from original-object fidelity and from exact additive lobe reconstruction.

A component-off control can leave energy in an event selection. Record the changed spatial pattern and residual separately; do not claim an exact isolated component or silently assign the residual to another mechanism without checking the renderer's event classification. The authored closure graph and the renderer's event bins are different evidence.

## Turn findings into a small knowledge graph

Use case-owned records with stable IDs rather than an unqualified bag of preset values:

`source cue → rival mechanism → component → field/constant → encoding and transform → shader input → expected event response → discriminating intervention → observed result → limitation`

Give each relation an evidence source and status: graph-observed, native-tested, image-hypothesized, or unresolved. Retain parameter values as exemplar settings with units and shader version, never as measured properties of the target photograph. Link the reusable mechanism to the relevant analysis, spatial-design, prompt, calibration and assembly stages.

Translate a selected mechanism into generation instructions explicitly: feature anchors, component ownership, shared/independent boundaries, angular behavior, allowed path content and a falsifier. For example, if a second reflection population is supported, request a matched comparison of a sharp core with a broad shoulder against a single-width rival, while freezing relief, pigment, light and view. That is an appearance hypothesis; later prompts must request separate intrinsic fields without highlights. Do not ask image generation to bake the exemplar's view-dependent color into pigment or to reproduce labeled AOVs by name alone.

Keep research and reconstruction separate. Source graphs/maps can teach mechanisms and supply behavioral controls, but a later strictly single-image trial must withhold the target's authored graph, maps and extra views until evaluation. If target parameters or maps are reused, label it an assisted reconstruction.

## Useful primary sources

- [ASWF MaterialX Teapot and Lion](https://dpel.aswf.io/materialx-teapot-lion/): modular layered/mixed BSDF examples with layer-specific maps; inspect the actual graph and license.
- [ASWF OpenPBR examples](https://github.com/AcademySoftwareFoundation/OpenPBR/tree/main/examples): compact optical controls; pin a revision and inspect color-space/unit declarations.
- [NVIDIA MaterialX/OpenPBR library](https://github.com/NVIDIA-Omniverse/PhysicalAI-SimReady-Materials): inherited USD material graphs; active connections matter more than the shared template size.
- [MaterialX PBR specification](https://github.com/AcademySoftwareFoundation/MaterialX/blob/main/documents/Specification/MaterialX.PBRSpec.md): component and combination semantics; check the implementation installed in the target runtime.
