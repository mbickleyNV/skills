# Comparison and acceptance record

## Contact sheet layout

Use consistent row/column roles rather than unrelated attractive thumbnails. For example: rows are body response, reflection, a relevant layer test, and beauty; columns are generated prediction and native response. Put source identity crops beside the sheet, not under a false “ground-truth lobe” label. Include separate closeups of defining features. Select panels for the actual material; transmission/coat/fuzz/etc. require their own studies or ablations when relevant.

Use one documented display conversion/exposure for comparable native passes. Extra boosted diagnostic previews may be shown if explicitly labeled with their gain and kept separate from the comparison. Preserve native linear data, version/settings, and processed preview provenance.

Use a source-like patch or supplied object for spatial/scale comparisons and a proper shader ball for curvature response. Render a shared specimen/view/light proxy for generated/native comparisons when practical. Imagegen's compliance with a matching prompt is not guaranteed; inspect it. A patch against a ball or different lights cannot establish a pixelwise reconstruction error. Even a well-matched generated image usually supports qualitative appearance comparisons only.

## Acceptance findings

Include morphology/profile and component-control criteria, not only lobe coverage. Record one row per defining feature or mechanism:

`criterion ID | source region/evidence | expected behavior | generated study | native test | pass/fail/uncertain | material limitation versus comparison confounder | next action`

Examples of discriminating findings:

- Reflection width differs: establish light angular size and geometry first, then bracket roughness under fixed illumination before changing pigment.
- Recesses look polygonal: inspect color contours, height profiles, UV aspect and neutral-color geometric response separately. Do not assume more mesh subdivisions repair angular pigment.
- A richer color revision introduces cracks or embossed grain: reject the structural regression and return the changed/locked feature contract to generation.
- One region cannot be recolored without resizing detail: inspect whether macro coloration, coverage and repeatable detail were collapsed into one field.
- Fine grain appears in beauty but not the reflection control: isolate albedo and normals; establish whether relief is connected and sampled adequately.
- A joint is a bright line rather than a dark cavity across oblique views: inspect real depth, bevels, normals and lighting; increasing normal strength cannot establish missing geometric occlusion.
- Coat highlights follow substrate scratches despite an apparently smooth coating: inspect layer coverage and separate normal paths, then test the physical hypothesis.
- A colored interior varies incorrectly with thickness: verify geometry scale, absorption interpretation and thickness before generating painted darkening.

Separate uncertainty about the unseen physical object from a visible failure that can be corrected. Neither unknown composition nor approximate lobes excuses missing the visible defining details.

## Make crop scale and verdicts auditable

Record source/field/render crop rectangles and display resampling. Align a
recognizable feature's apparent width or spacing where possible; preserve image
aspect. Report uncertain physical scale and compare relative distributions rather
than inventing millimeter correspondence. Use several characteristic regions when
one attractive crop omits rare features or quiet land. Image statistics can support
inspection, but a matching histogram/spectrum does not prove correct connectivity
or profile.

Use three findings: **execution** (the graph runs), **mechanism influence** (the
intended intervention changes native behavior), and **source fidelity** (defining
appearance survives). Each can pass, fail or remain uncertain independently. A
source-fidelity failure remains failed in a technically complete prototype. Update
current assessments when new inspection or user feedback exposes a miss; preserve
older conclusions as superseded history rather than silently rewriting evidence.

## Quality decision

Technical validity is necessary but insufficient. For the stated high-fidelity target require defining features to pass at intended presentation scale and close inspection, with relevant changed-light/view tests. Assess map resolution, filtering, sampling and denoising effects rather than assuming a large output or sample count guarantees quality. Choose enough sampling to distinguish material behavior from noise; do not launch release-scale tests for creative review.

Report failures candidly and keep working when a useful correction is available. If progress stalls, change the experiment or identify the specific capability/observation needed. Do not spend unlimited identical generations, declare victory from an attractive beauty, or invent a budget the user did not set.

## Reject compensating matches and incomplete complexity

Inspect the response benchmark and source-like proxy for their declared purposes. A fit transferred to a new thickness, UV repeat or geometry must revalidate affected assumptions. Compare source/native at similar object scale, then matched feature crops; cropping is presentation, not geometric registration. Maintain image aspect and identify the same regions. Never declare a quantitative color match from unrelated exposure, camera or display conditions.

For high fidelity, report separately: visible feature preservation; optical mechanism/input coverage; physical representation; editable component independence; cross-condition robustness. A high lobe count cannot offset wrong motifs, and a convincing color family cannot certify the physical absorption coefficient. Put the strongest unresolved defining failure ahead of minor polish.

Require an interaction check where the hypothesis depends on layers affecting one another. Distinguish an input connected to the graph from an input proven to change the intended native response. Unavailable effects remain limitations even if the beauty is attractive. Technical convergence, complete paperwork and generated contact-sheet count do not establish visual acceptance.

## Series built from web references

Choose cases for different evidenced mechanisms and interactions, not merely different colors. Freeze one identity photograph per case before reconstruction. Record source URL, image identity/hash and permitted research use; do not bundle source photos in reusable skills. Separate photograph-only inference from information learned from captions or technical research, and never describe published product metadata as visually recovered. Avoid accessing reference shader graphs or texture sets when claiming a single-image attempt.

Evaluate each case against its own defining features and shared benchmark. A collection of valid graphs is not a fidelity pass. Summarize active mechanisms, native influence evidence, unresolved representation limits and source-to-render deltas for each. Distill only demonstrated or explicitly conditional lessons back into skills; retain product-specific parameters in case data.

## Detail survival gate

Inspect the final displayed image as well as a crop. A detailed input texture and a connected normal node do not establish visible detail. For ordered structures, check intermediate morphology, direction and grazing response; for layered flakes, check glints and the smooth outer interface independently. Report changes that only enlarge features as artistic scale compromises, and retain a failed representation as failed even when its beauty render is attractive.
